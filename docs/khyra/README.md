# Khyra Conversational Message Library

Central library: 703 events across 47 modules. Every event has four variants; issues also have an urgent variant.

Prepared entries are labelled **Prepared template — not connected to a verified ERP trigger**. They do not render in live mode and expose no available actions.

This is a message catalog, not a second notification backend. Catalogued source does not mean an automatic producer has been wired. The exact live bindings are in lib/khyra/bindings.ts. Unknown existing feedback is preserved rather than guessed.
