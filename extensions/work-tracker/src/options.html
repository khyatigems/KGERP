Connect Chrome to your ERP

Install once, connect once, then enable automatic tracking. Marketplace switching needs no task timers.

Use http://localhost:3000 for your local ERP or https://erp.khyatigems.com for the deployed ERP. The credential must come from the same ERP.

Create a credential in Marketplaces / Work Tracker / Connections. It is stored on this Chrome profile and can be revoked in ERP. Never paste marketplace OAuth credentials.

After saving, open the pinned extension and click Enable automatic tracking once. Only an eligible active marketplace tab in a focused window counts. ERP work is tracked directly in ERP; the sensor excludes ERP tabs.

Recent intervals wait for the idle threshold plus 90 seconds before upload (about seven minutes by default). Sync now does not bypass this idle-safety buffer. No screenshots, forms, page titles or full URLs are stored.

Disconnect clears this profile’s saved credential after the pending queue is empty. Revoke the old named credential in ERP as well.

Changing ERP or credential requires syncing or clearing the old pending queue first. Offline records older than seven days require manual review.
