Work Tracker Settings

Tracking starts only when you enable automatic tracking in the popup. Only the eligible active tab in a focused browser window counts.

Create a credential in Marketplaces / Work Tracker / Chrome connection. It is stored on this Chrome profile and can be revoked in ERP. Never paste marketplace OAuth credentials.

Recent intervals wait for the idle threshold plus 90 seconds before upload. Idle time is removed. Gaps over 90 seconds are discarded after suspension. Restart never counts closed-browser time. No page contents, titles, forms or full URLs are stored.

Changing ERP or credential requires syncing or clearing the old pending queue first. Offline records older than seven days require manual review.
